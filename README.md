# Сайты зоосалонов

В репозитории два сайта.

## 1. «Оскар» (корень репозитория)
Рабочий лендинг для конкретного салона. Содержит реальные фото, адрес, телефон и отзывы клиента.
**В портфолио не показывать.** Закрыт от индексации (`noindex`).

- `index.html`, `script.js`, `assets/`

## 2. «Мягкая лапа» (папка `demo/`)
Учебный проект для портфолио на основе структуры «Оскара». Название, цены, отзывы, мастера и контакты
вымышлены, вместо фото иллюстрации. Реальных данных клиента здесь нет.

- `demo/index.html`, `demo/style.css`, `demo/script.js`
- Адрес после публикации: `https://agnia777.github.io/oscar-demo/demo/`

Как адаптировать демо под нового клиента: заменить название, тексты, цены и контакты в `demo/index.html`,
а иллюстрации `<svg><use href="#pet-…"/></svg>` на настоящие фото `<img>`.

Локальный просмотр: `python3 -m http.server` и открыть http://localhost:8000 (или `/demo/`).

## Публикация через Vercel
Из этого репозитория делаются два независимых Vercel-проекта (Framework Preset: **Other**, команда сборки и Output Directory пустые):

| Проект | Root Directory | Что публикуется |
|---|---|---|
| «Оскар» (для владелицы) | `./` (корень) | `index.html`, `script.js`, `assets/`; `.vercelignore` скрывает `demo/`, `CLAUDE.md`, `README.md`, `.github` |
| «Мягкая лапа» (портфолио) | `demo` | содержимое папки `demo/` |

«Оскар» закрыт от индексации (`noindex` и `robots.txt`), у демо этого нет.

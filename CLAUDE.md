# Правила проекта

Автор репозитория делает сайты для груминг-салонов и собирает портфолио. Общаться по-русски.

## Принцип: делаем современные сайты
- Сайт должен быть живым и современным, а не статичной страницей. Анимация обязательна:
  - появление блоков при прокрутке со ступенчатой задержкой;
  - анимированный заголовок и первый экран (плавающие элементы, мягкие фоновые пятна);
  - микровзаимодействия: hover-эффекты, наклон карточек, блики и пульсация на кнопках;
  - анимированные счётчики, индикатор прокрутки, «оживающие» иллюстрации (моргание, покачивание).
- Анимация не должна мешать читать и пользоваться. Всегда уважаем `prefers-reduced-motion`: при нём
  все анимации отключаются, а контент остаётся видимым.
- Сайт должен хорошо выглядеть на телефоне (проверять ширину 390px, без горизонтальной прокрутки).
- Все интерактивные элементы доступны с клавиатуры, есть видимый `:focus-visible`.

## Данные клиентов
- Корень репозитория («Оскар») — рабочий сайт конкретного салона. Реальные фото, телефон, адрес и
  отзывы клиента остаются только там и в портфолио не показываются.
- Папка `demo/` («Мягкая лапа») — публичное портфолио. В ней только вымышленные данные и иллюстрации,
  никаких реальных фото, имён, контактов и текстов клиента.

## Техника
- Статические сайты без сборки: `index.html`, `style.css`, `script.js`.
- Публикация через GitHub Pages.
